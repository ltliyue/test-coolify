## TC-01: 空配置

| 步骤                     | 预期             |
| ------------------------ | ---------------- |
| GET /brands（新 agency） | 200, {} 或默认值 |

## TC-02: 完整更新

| 步骤                              | 预期           |
| --------------------------------- | -------------- |
| PUT /brands {colors, fonts, tone} | 200            |
| GET 再次                          | 返回已保存配置 |

## TC-03: PATCH 合并语义

| 步骤                               | 预期                         |
| ---------------------------------- | ---------------------------- |
| PUT {colors: {primary: "#FF0000"}} | 仅更新 primary，其他颜色保留 |
| PUT {fonts: {heading: "Georgia"}}  | fonts 合并，colors 保留      |

## TC-04: 重置

| 步骤           | 预期      |
| -------------- | --------- |
| DELETE /brands | 204       |
